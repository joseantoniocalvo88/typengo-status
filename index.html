03 / TRANSPARENCIA

Acerca de este monitor

El alojamiento es independiente de TypeNGo. Las pruebas HTTP no consultan directamente la base de datos, no crean sesiones y no ejecutan IA. Los componentes sin comprobación específica se muestran como no monitorizados. Los retrasos y los intervalos sin datos no se contabilizan como servicio disponible.

Los datos se conservan hasta 90 días en la vista, sujetos al histórico disponible. Esta página no es un SLA.
